Connect a repository
Add the bot to any GitHub repo in three steps. Takes about two minutes.
Step 1
Add a webhook to your repository
Go to your repo → Settings → Webhooks → Add webhook.
Payload URL: https://pr-review-agent-production-9f8e.up.railway.app/webhook
Content type: application/json
Events: Pull requests only
Step 2
Set the webhook secret
Enter your shared secret in the webhook's Secret field so the server can verify events are genuinely from GitHub.
WEBHOOK_SECRET=your_secret_here
Step 3
Open a pull request
The next time anyone opens a PR on that repo, the three agents run automatically and post a structured review within 30 seconds.
git checkout -b your-feature-branch
git push origin your-feature-branch
# open a PR on GitHub — the bot handles the rest
